# Desk-Telemetry
PowerShell and AWS based workstation occupancy monitoring solution. Show more lines

1 Desk Telemetry

Desk Telemetry is a workstation occupancy monitoring solution that uses PowerShell and AWS serverless services to identify desk usage in real time.

2 Project Goals

- Monitor workstation occupancy
- Detect connected users
- Detect monitor status
- Identify available desks
- Provide real-time visibility for workspace utilization

3 Technologies

- PowerShell
- AWS Lambda
- API Gateway
- DynamoDB
- CloudWatch
- Windows Scheduled Tasks

4 Current Features

- User detection
- Computer detection
- Monitor status monitoring
- Telemetry collection
- Real-time dashboard
